What the automation does

Every cell above is computed from one array of dates — the same CHAPTERS array already running on the live site. Press Aug 15 · rollover and watch it happen with nobody editing anything: IBM leaves Now, Workiva takes its place with the week counter reset to 1, and Next becomes the full-time role. On Jan 14 the full-time role becomes Now and Next empties out. The only edit you ever make is adding one entry when a role is announced.

How the redaction is implemented

A chapter gets one extra flag — secret:true — and the renderer swaps the company for a fixed-width redacted span while keeping everything else about the cell identical:

{from:'2027-01-14', what:'Full-time', co:'█████████', secret:true}

Three details that matter more than the effect itself. The character count is fixed and the face is monospace, so the cell never changes width while the animation runs — a strip that jitters would read as broken, not clever. The real company name is never in the HTML, so nobody can find it in view-source; the placeholder is all that ships. And the span carries aria-label="company not yet announced" so a screen reader gets the meaning instead of a mouthful of block characters.
