How this works in the real build
One ~1KB script tag (Plausible) — no cookies, no banner, GDPR-safe, doesn't touch site performance. Custom events fired from the existing flyTo() function mean every frame visit is tracked automatically. Extra events: resume_download, tour_started / tour_completed, lens_se / lens_ae — so you learn which stories recruiters actually open, and whether SE or AE traffic dominates.
