# saaifkhan.com — Site Structure (v1)

Every mockup follows this same skeleton. Content is placeholder until the content pass.

## Landing
- Name + one-line identity statement
- Two primary paths: **Personal** and **Professional**
- Quick links: email, LinkedIn, resume download

## Personal
- Intro blurb (who Saaif is off the clock)
- Hobbies & interests — each expandable into detail (photos, story, why it matters)
- "Currently into" section (books, shows, projects, whatever's active)

## Professional
- High-level summary: headline, current status, 3-4 stat highlights
- **Education → UT Dallas** (drill-down)
  - Degree, major, timeline, GPA (optional)
  - Coursework list — each class clickable for a one-line "what I learned"
  - Orgs, honors, activities
- **Experience** (drill-down per role)
  - e.g., **IBM — [Position Title]**: duration, team, full breakdown of what the summer entailed, skills used, outcomes
  - Pattern repeats for every other role
- **Skills** — grouped (technical / tools / soft)
- **Projects** (optional section, same drill-down pattern)

## Contact / Footer
- Email, LinkedIn, resume
- Consistent on every view

## Interaction model
Landing → pick a path → summary level → click any item → full detail. Never more than 2 clicks from landing to any piece of information.
